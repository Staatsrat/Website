Selected Work

  • SignStrike Defensive Windows tool that detects kernel modifications — monitors callback tables, loaded drivers and system service tables for unauthorized changes and raises an alert.
  • icmp_communication Covert communication channel over ICMP packet sizes. Instructions are encoded in the echo request length — no payload needed.
  • tor_keep Tor connection monitoring and keep-alive utility.
